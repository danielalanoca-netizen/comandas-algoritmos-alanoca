# Descripción del proceso a optimizar

En Coffeeology, el control de inventario se realiza mediante revisiones manuales de las materias primas. El personal de los diferentes turnos identifica los productos que faltan o necesitan reposición y comunica esta información al encargado de la noche, quien reúne los datos y prepara la lista de compras.

Este proceso puede tomar entre 30 minutos y una hora, debido a la cantidad de materias primas que se deben revisar, que puede alcanzar aproximadamente 450 registros.

El objetivo del proyecto es analizar este proceso y evaluar estructuras de datos y algoritmos que permitan mejorar la búsqueda y consulta de información del inventario.
