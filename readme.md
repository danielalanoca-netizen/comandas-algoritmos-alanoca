# Proceso lento identificado en Coffeeology

1 El proceso seleccionado es la búsqueda de productos para registrar una comanda en Coffeeology.
2 Este proceso se realiza durante la atención y registro de pedidos de los clientes.
3 Los trabajadores encargados de registrar las comandas son quienes realizan esta tarea.
4 Para agregar un producto, necesitan localizarlo dentro del catálogo disponible.
5 La búsqueda puede resultar lenta cuando existe una gran cantidad de productos registrados.
6 El proceso requiere identificar correctamente el producto solicitado.
7 Actualmente, estudiamos como se realiza la busqueda y la verificacion de cantidad de stock.
8 El catálogo contiene aproximadamente 200 productos.
9 La búsqueda de un producto tarda aproximadamente 2 min * producto.
10 Cuando se realizan varias comandas, estas búsquedas se repiten constantemente.
11 Esto puede incrementar el tiempo necesario para registrar los pedidos.
12 El objetivo es encontrar una manera de optimizar este proceso sin alterar los resultados.
