# Descripción del proceso a optimizar

1. En Coffeeology, el personal debe localizar y verificar los productos solicitados por los clientes antes de agregarlos a una comanda.
2. Algunos productos son habituales y el trabajador conoce su disponibilidad; otros requieren una revisión manual.
3. La verificación consiste en consultar el stock para confirmar si el producto cuenta con unidades disponibles.
4. Este proceso es realizado por el personal encargado de atender a los clientes y registrar sus pedidos.
5. Cuando un producto no es habitual o existe duda sobre su disponibilidad, el trabajador debe revisar manualmente el inventario.
6. Esta revisión puede tardar aproximadamente entre 1 y 2 minutos por producto.
7. El tiempo empleado aumenta cuando una comanda contiene varios productos que necesitan verificación.
8. Esta demora afecta al personal de atención y a los clientes que esperan realizar sus pedidos.
9. Para analizar el proceso se utilizará una muestra de 20 registros de productos en el formato del catálogo.
10. El catálogo preliminar elaborado a partir del menú contiene aproximadamente 135 opciones seleccionables, cantidad pendiente de verificación con el inventario real.
11. Se implementará en Python un algoritmo de búsqueda lineal como punto de partida para estudiar la eficiencia de la búsqueda de productos.
12. El objetivo es analizar el proceso y evaluar una alternativa que permita localizar información de productos de manera más eficiente.
