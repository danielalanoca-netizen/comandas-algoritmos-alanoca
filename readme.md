# Descripción del proceso a optimizar

1. En Coffeeology, el personal debe buscar productos del catálogo al momento de registrar una comanda.
2. Este proceso consiste en localizar el producto solicitado por el cliente y seleccionarlo para agregarlo a la comanda.
3. La búsqueda se realiza utilizando el código o nombre del producto.
4. El proceso es realizado por el personal encargado de atender a los clientes y registrar sus pedidos.
5. Cuando el catálogo contiene muchos productos y variantes, encontrar el artículo correcto puede tomar tiempo.
6. Esta demora afecta principalmente al personal de atención y a los clientes que esperan realizar su pedido.
7. El proceso se repite cada vez que se registra una comanda y puede involucrar varios productos.
8. Para analizar el problema se utilizará una muestra de 20 registros de productos en su formato de catálogo.
9. El catálogo preliminar elaborado a partir del menú contiene aproximadamente 135 opciones seleccionables, cifra que debe verificarse con el catálogo real del negocio.
10. Actualmente se necesita medir cuánto tiempo tarda el personal en localizar y agregar un producto para establecer una referencia real.
11. Como punto de partida, se implementará un algoritmo de búsqueda lineal en Python para analizar el comportamiento del proceso.
12. El objetivo es estudiar su eficiencia y posteriormente compararlo con una alternativa de búsqueda más rápida.
